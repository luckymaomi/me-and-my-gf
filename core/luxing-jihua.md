# 旅行计划制定

## 说明

```
旅行计划制定
1. 场景：出一份详细旅行计划；改口径改本文件
2. 能干：多搜当地资料；按做计划框架把衣食住行吃喝玩乐写全；分开写推荐和避雷；最后附行装
3. 铁律：人少偏僻风景好；绝不网红；没驾照所以不开车、不租汽车；住必须安静；能省则省
4. 节奏：先对口径 → 再反复搜索 → 再按模板出详细计划；缺关键信息先问
```

---

## 一、做计划框架

做计划时，下面这些方面都要过一遍，计划里都要写到。

| 方面 | 要想清楚什么 | 计划里写在哪 |
| --- | --- | --- |
| 去哪 | 什么样的地方；地方定了就深挖，没定就给几个备选 | 开头说明；需要时写备选 |
| 不去哪 | 网红、人挤、商业古镇这类一律排除 | 避雷清单里的玩 |
| 怎么去（城际） | 高铁、动车、飞机、顺风车、大巴等；已经定好的交通就按那个写 | 推荐清单里的行；细项「怎么到」 |
| 到了怎么走 | 两轮电瓶车、自行车、步行；能坐地铁公交也行 | 推荐和避雷里的行；租车细节 |
| 住 | 安静、便宜、能做饭；多家对比 | 避雷和推荐里的住；住宿对比表 |
| 吃 | 自己煮、菜市场、本地小馆 | 避雷和推荐里的吃；细项「怎么吃」 |
| 玩 | 免费乡道、村落为主；要买票的单独说值不值 | 避雷和推荐里的玩；细项「怎么逛」 |
| 喝 | 水、当地的茶饮料；别净靠景区贵水 | 吃喝推荐里；注意里也可提 |
| 乐 | 闲逛、走路、看山看田；别搞特种兵打卡 | 玩的推荐主线 |
| 注意 | 信号、蚊子、下雨、电瓶车没电、叫不到车、暴雨涨水等 | 细项「当地注意」 |
| 花钱 | 能省就省；住宿先看百元上下；贵景点可以不去 | 选推荐时一直要掂量 |
| 行李 | 出门带什么；收拾时按清单勾 | 计划最后「必须带的东西」 |

### 计划写成什么样（顺序）

1. 避雷清单（住 / 吃 / 玩 / 行）  
2. 推荐清单（住 / 吃 / 玩 / 行）  
3. 住宿对比表（至少 5 家，能多就多）  
4. 细项：怎么到、住哪、怎么逛、怎么吃、怎么走、当地注意  
5. 必须带的东西（收拾行李用）

### 搜索和条数

| 关于 | 怎么做 |
| --- | --- |
| 搜索 | 携程、美团、游记、点评多看看；住吃玩行都多搜几轮；店名和票价别瞎编 |
| 推荐 | 住、吃、玩、行每类尽量多写，至少 5 条，能超过 5 就超过 |
| 避雷 | 同样分类写；尽量够 5 条；实在搜不到那么多就少写，别硬凑 |
| 住宿对比 | 至少 5 家，能多就多 |
| 价格 | 写「大约多少」；旺季会变，订之前再看一眼 |

## 二、去哪/不去哪

| 关于 | 怎么做 |
| --- | --- |
| 去哪 | 人少、偏僻、风景好：深山村落、冷门县域、未开发乡道、多山多林 |
| 不去 | 网红打卡、人挤景区、商业古镇、热闹市中心观光线 |
| 花钱 | 能省就省；别为了「方便」住到热闹吵的地方 |
| 地方已经定了 | 就深挖这一个，按做计划框架写全 |
| 地方还没定 | 给两三个备选；每个写清怎么到、住哪一片、菜市场、白天怎么逛、晚上怎么自己做饭 |

## 三、衣

| 关于 | 怎么做 |
| --- | --- |
| 怎么带 | 看天气和走不走路；轻便好洗，少带备用 |
| 温差大 | 季节或山上山下温差明显时，计划里加减冲锋衣、拖鞋之类 |
| 不好洗衣的地方 | 多带内衣裤类快干的，外套少带几件 |
| 计划里 | 行李按气温勾；需要的话提一句走路穿什么 |

## 四、吃/喝

| 关于 | 怎么做 |
| --- | --- |
| 自己做 | 煮、炖、涮（电煮锅）；晚上默认大乱炖或小火锅；菜对照「我会做的」 |
| 买菜 | 到了先找农贸市场：鲜切肉、青菜、馒头或面条、水果；肉在市场切好 |
| 下馆子 | 买菜不方便或太累时；找清净的本地馆子；不推网红店 |
| 喝的 | 自己带或镇上买水；少买景区里贵的瓶装水 |
| 推荐怎么写 | 写出店名或「某条路的农家菜」、推什么菜、大概人均；买菜点写大概在哪 |
| 避雷怎么写 | 宰客、不新鲜、专坑游客的网红店、节假日虚高套餐——写出名字或类型 |

## 五、住

| 关于 | 怎么做 |
| --- | --- |
| 一定要 | 清静、安静 |
| 住哪一片 | 偏安静的地方、山边村里；别住热闹街边、景区门口 |
| 订之前问清楚 | 安不安静、旁边吵不吵；普通插座能不能撑住 1000W；能不能借水槽洗菜或借张空桌插电做饭 |
| 推荐 | 安静、评价靠谱、便宜或性价比高；能做饭、插座够更好；写上大概价、为什么推、上面三句问话 |
| 可以考虑 | 便宜但旧一点，或多花一点但明显更安静——把取舍说清楚 |
| 避雷 | 有味、有虫、卫生差、节假日乱涨价、隔音差、乱收费——写出名字和差评要点 |
| 好评差评都有 | 可以写「想订的话先验房或看近照」，并写可能翻车的信号 |
| 价钱 | 优先大约一百到两百出头；更贵的只在安静或做饭实在满足不了时再考虑 |
| 对比表 | 至少 5 家：名字、大概价、推荐 / 可考虑 / 避雷、一句话理由 |

## 六、行

| 关于 | 怎么做 |
| --- | --- |
| 开车 | 没有驾照，不开车，也不租汽车、不自驾 |
| 城际 | 高铁、动车、飞机、顺风车、公交大巴等，往便宜的选；已经订好的（比如顺风车）就按实际写进计划 |
| 到了当地 | 优先两轮电瓶车或自行车，或者走路；能坐地铁公交也行；写清车站到住处、住处到市场或山里怎么走 |
| 租电瓶车 | 写清去哪租（镇口、酒店门口、车行）、大概一天多少钱；按天租通常比按小时划算；可以砍价 |
| 租车要注意 | 电别跑太狠；天黑乡路没灯；押金、证件、还车问清楚；刹车不灵、灯不亮的不租；搜不到店名就写「到某某路口问几家比价」，别瞎编店名 |
| 白天怎么逛 | 往山里、村里转；别排一串打卡点 |
| 叫车 | 冷门镇子经常叫不到网约车；回去的车提前约顺风车、拼车，或问民宿帮忙 |

---

## 七、玩/乐

| 关于 | 怎么做 |
| --- | --- |
| 主线 | 乡道、古桥、村落、山里田园；免费够看就别买票 |
| 怎么玩 | 散步、闲逛、适度走路爬山；节奏松一点 |
| 要买票的 | 单独写大概多少钱、值不值；不值就写可以不去 |
| 不推 | 纯网红打卡、人挤景区、套票连着玩 |
| 推荐怎么写 | 路线或名字 + 免费还是收费 + 大概多久或怎么骑过去 |
| 避雷怎么写 | 贵又不值、人挤、本来就不想去的——写出名字 |

---

## 八、当地注意

计划细项里单独写一小节，常见要查、要写的有：

| 关于 | 怎么做 |
| --- | --- |
| 信号 | 有的乡道信号差 |
| 蚊子 | 田野多，带驱蚊 |
| 下雨涨水 | 暴雨路可能积水；带雨具 |
| 电瓶车 | 电够不够、天黑有没有灯 |
| 叫车 | 能不能打到车；回去怎么走 |
| 导航 | 搜具体地名，别只搜笼统景区名，免得被带到售票口 |

### 4. 细项

#### 怎么到

城际怎么来；到了怎么接上。

#### 住哪

更想住哪一两家，备选是谁；订前三句问清楚。

#### 怎么逛

白天主线（免费优先）；可选的收费；慢慢逛。

#### 怎么吃

菜市场；自己做；下馆子备选。

#### 怎么走

租哪、多少钱、电和天黑注意；少打车。

#### 当地注意

信号、蚊子、雨、叫车、导航等。

### 5. 必须带的东西（收拾行李时勾）

尽量少带；当地能买的就别装包。每次出门按这张表勾一遍。

| 类别 | 物品 |
| --- | --- |
| 证件与电子 | 身份证、手机、充电器、充电宝 |
| 洗漱与日用 | 牙刷、牙膏、毛巾、餐巾纸、湿巾、一次性内裤、常用药、创可贴、轻便雨具 |
| 自炊 | 美的 2.6L 分体式电煮锅（1000W）、硅胶折叠碗、一次性筷子、便携小刀、迷你切菜板、无纺布袋（包锅）、垃圾袋、调料盒（盐 / 酱油 / 油）、洗洁精、百洁布 |
| 看情况加减 | 驱蚊（田野蚊子多时）；冲锋衣 / 拖鞋（温差或要走路时） |
