# 我会做的

## 说明

```
我会做的
1. 场景：查或改会做的菜
2. 能干：按菜名查；增删改；旅行/每日饮食点菜时对口径
3. 铁律：只记本文件已有菜；不编未写步骤
4. 节奏：默认只查；要改先备份再写
```

---

| 菜名 | 材料 | 做法 |
| --- | --- | --- |
| 土豆炖牛肉 | 土豆，番茄，牛肉 | 土豆不要切太小，番茄对半切，牛肉切成小块。一起放高压锅压 50 分钟后放盐。 |
| 青椒丝瓜炒猪肉 | 青椒，丝瓜，猪肉 | 青椒切丝，丝瓜切片，猪肉肥瘦分开。肥猪肉榨油，榨干炒瘦肉，炒 30 秒放青椒丝瓜，炒到丝瓜塌下来，放一铲子老抽放盐。出锅。 |
| 青椒牛肉 | 青椒，牛肉 | 青椒切丝，油热下青椒，炒香放牛肉，炒熟出锅。 |
| 蒸鲈鱼 | 鲈鱼，大葱，生姜 | 腌 10 分钟（鲈鱼对半，大葱生姜塞里面），水开后鲈鱼趴着蒸 8 分钟；油烧冒烟，调少量水+生抽，先淋热油再淋调料。 |
| 蒸牛肉 | 牛肉，姜，蒜 | 腌 10 分钟（牛肉，油，少量生抽，姜丝，蒜末）。水开蒸 10 分钟。 |
| 蒸虾 | 虾，姜，蒜 | 虾冷冻 20 分钟，盘底铺姜片、蒜，水开蒸 7 分钟。 |
| 炒菠菜 | 菠菜，蒜 | 水开烫菠菜 30 秒去草酸，热锅热油放蒜炒香，放菠菜炒熟。 |
| 韭菜鸡蛋 | 韭菜，鸡蛋 | 鸡蛋 4 个打匀，韭菜切碎混入，热锅热油倒入炒熟。 |
| 炒鸡 | 鸡，洋葱，姜 | 腌鸡（盐焗鸡粉，少量油）。热锅热油，下全部姜、一半洋葱炒香，放鸡中火炒，水快干换小火，再放剩余洋葱炒到鸡彻底干、锅里不出水。 |
