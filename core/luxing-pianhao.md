# 旅行偏好

## 说明

```
旅行偏好
1. 场景：做旅行计划；改偏好改本文件
2. 能干：按总原则 + 衣食住行出方案；行装按清单
3. 铁律：人少偏僻风景好；绝不网红；不租汽车自驾；住必须安静
4. 节奏：先对偏好再出路线；不确定先问
```

---

## 总原则

| 关于 | 怎么做 |
| --- | --- |
| 去哪 | 人少、偏僻、风景好：深山村落、冷门县域、未开发乡道、多山多林 |
| 不去 | 网红打卡、人挤景区、商业古镇、热闹市中心观光线 |
| 成本 | 能省则省；不为「方便」换成热闹片区 |
| 计划 | 给 2～3 个备选点；写清怎么到、住哪片、菜市场、白天怎么逛、当晚怎么自炊 |

---

## 衣食住行

### 衣

| 关于 | 怎么做 |
| --- | --- |
| 怎么带 | 按气候与徒步强度；轻便好洗，少带备用 |
| 温差 | 有明显季节或海拔温差时，计划里加减（冲锋衣、拖鞋等） |
| 冷门地 | 洗衣不便时多带内衣裤类快干件，少带外套 |

### 食

| 关于 | 怎么做 |
| --- | --- |
| 自炊 | 煮、炖、涮（电煮锅）；当晚默认大乱炖或小火锅；菜谱对照「我会做的」 |
| 买菜 | 到站先找农贸市场：鲜切肉、青菜、馒头或面条、水果；肉在市场切好 |
| 外食 | 买菜不便或太累时；优先清净本地馆子，不推网红店 |

### 住

| 关于 | 怎么做 |
| --- | --- |
| 硬条件 | 必须清静安静 |
| 选址 | 偏安静片区、山边村里；不选热闹街边、景区门口 |
| 预订前确认 | 是否安静；普通插座能否扛 1000W；能否借水槽或空桌做饭 |

### 行

| 关于 | 怎么做 |
| --- | --- |
| 前提 | 没汽车、不会开车；不租汽车、不自驾 |
| 城际 | 高铁 / 动车 / 飞机 / 顺风车 / 公交大巴等；往便宜算，写清花费与换乘 |
| 落地 | 优先两轮或步行；可接地铁公交；写清站 → 住处 → 市场 / 山里 |
| 白天 | 往山里、村里闲逛；不排打卡点 |
