# 旅行偏好

## 报装

```
旅行偏好
1. 场景：做旅行计划前对齐口味；改偏好也改本文件
2. 能干：按必需品 / 衣 / 食 / 住 / 行出方案；避坑提醒
3. 铁律：以本文件为准；不推网红挤人线；不租汽车自驾
4. 节奏：先对偏好再出路线；不确定先问
```

## 综述

```
旅行偏好已对齐。按必需品与衣食住行出计划；清净优先，不租车自驾。
```

---

## 总原则

1. 清净：人少、偏远、风景好的地方（深山村落、冷门县域、未开发乡道）。避开人挤景区、商业古镇、网红打卡。
2. 节奏：散步、闲逛、适度爬山徒步可以；不赶路、不特种兵。
3. 语言：直接、实用；不用「绝美 / 必打卡」这类词。
4. 计划产出：给 2～3 个符合偏好的备选点；写清大交通接驳、住哪片、菜市场、当晚怎么自炊、白天怎么闲逛。

---

## 必需品

每次出门默认带齐；计划里可按季节加减，不默认删下面硬项。

### 证件与电子

- 身份证、手机、充电器、充电宝

### 日用品

- 餐巾纸、湿巾、一次性内裤、基础洗漱
- 一小包常用药、创可贴
- 轻便雨具（雨天或徒步时）

### 炊具与餐具

- 美的 2.6L 分体式电煮锅（1000W，不带蒸笼）
- 硅胶折叠碗、木筷子、便携小刀、迷你切菜板
- 结实无纺布袋（包电煮锅防刮防油）、垃圾袋
- 短插排（插座不稳或 1000W 不够方便时）

### 调料与清洁

- 便携式调料盒：盐、酱油、油
- 小瓶洗洁精、剪好的小块百洁布

### 到了再买

- 当地农贸市场：鲜切牛肉 / 肉片、青菜、老面馒头或面条、当地水果

---

## 衣

1. 以当地气候与徒步强度定；默认轻便好洗，少带备用。
2. 有明确季节或海拔温差时，计划里单列加减（冲锋衣、拖鞋等），不写死品牌清单。
3. 洗衣不便的冷门地：多带内衣裤类快干件，少带外套件数。

---

## 食

1. 口味：湖南、微辣；自炊以煮、炖、涮为主（受电煮锅限制）。
2. 到站先找农贸市场；推荐应季菜和当地能买到的肉菜面点。
3. 当晚默认：民宿里做一顿微辣大乱炖或小火锅；菜谱可对照「我会做的」。
4. 外食：只在买菜不便或太累时用；仍优先清净、本地人吃的馆子，不推网红店。

---

## 住

预订前必须让我向民宿 / 农家院老板确认这三句：

1. 环境是否够安静，周围有没有噪音源。
2. 房间普通插座能否扛 1000W，会不会跳闸。
3. 能否借厨房水槽洗菜，或借一张空桌插电做饭。

选址：偏安静片区；不为「市中心方便」牺牲清净。

---

## 行

1. 大交通：高铁 / 动车 / 飞机。
2. 绝对不租汽车、不自驾。
3. 落地后：优先租两轮电瓶车，或步行；计划写清站到住处、住处到市场 / 散步线的接驳。
4. 漫游：无目的闲逛、看完风景回住处做饭；不排打卡连环点。
